![alt text](image.png)# Project Images

Bỏ ảnh dự án vào folder này. Đặt tên file theo format:

- `bot.png` hoặc `bot.jpg` — Ảnh cho project Discord & Telegram Bot

- Thêm project mới: đặt tên file tùy ý, rồi update `src` trong `index.html`

**Kích thước khuyến nghị:** 800x450px (tỷ lệ 16:9)
**Format:** PNG, JPG, hoặc WebP
