# Music Files

Bỏ file nhạc vào folder này (`.mp3`, `.ogg`, `.wav`).

**Ví dụ:**
- `song1.mp3`
- `song2.mp3`
- `lofi-chill.mp3`

Sau đó mở file `script.js`, tìm `musicPlaylist` và thêm bài vào danh sách:

```js
const musicPlaylist = [
    { title: 'Tên bài 1', src: 'music/song1.mp3' },
    { title: 'Tên bài 2', src: 'music/song2.mp3' },
];
```
